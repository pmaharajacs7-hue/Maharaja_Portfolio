Zenith Hackathon

Store Lens

Smart Inventory Management System

Live Site GitHub APK Demo Video

An inventory management application built to improve inventory lookup and operational efficiency in retail stores and pharmacies. The idea came from a real problem at a college clinic, where a newly joined employee struggled to locate medicines, causing delays and repeated interruptions to the store owner.

Key features
  • JWT authentication & role-based access control
  • Inventory management with storage location tracking
  • Voice-enabled product search (OpenAI Whisper API)
  • REST APIs for inventory, employee & shop management
  • Android client (MIT App Inventor) on the live backend
My contribution

Independently designed and developed the complete backend using Java and Spring Boot — MySQL schema design, REST APIs, Spring Security with JWT-based authentication and role-based authorization, JPA/Hibernate integration, and OpenAI Whisper API integration for voice-based product search. Deployed the full application on Render (Spring Boot) and Aiven MySQL, and integrated the Android app with the live backend for end-to-end testing.

RESULTEvaluated at a college clinic — the newly joined employee reported significantly reduced time to locate medicines and fewer repeated interruptions to the store owner.

Sustainability Hackathon

Water Leakage Detection System

Smart Underground Water Distribution & Leak Detection

GitHub Demo Video DB Demo

Built at a Sustainability Hackathon sponsored by U.S.-based organizations. Conventional pipeline leak detection is expensive and infrastructure-intensive, limiting adoption in rural water networks — this project targets a scalable, low-cost alternative for villages and municipalities.

Key features
  • Live ESP32 sensor data ingestion in real time
  • EPANET/WNTR hydraulic simulation integration
  • Python ML anomaly-detection layer to flag leaks by location
  • Statistical feature engineering (rolling averages, std dev) to cut false alarms
  • Lightweight dashboard for affected pipeline segment identification
My contribution

Independently designed and implemented the complete backend using Spring Boot and MongoDB. Built REST APIs and the Java–Python integration layer to orchestrate EPANET/WNTR hydraulic simulations and ML inference, enabling real-time sensor data processing and persistent storage of pipeline analytics.

RESULTPresented to US-based hackathon sponsors, who gave funding and scalability feedback for real-world village deployment.
